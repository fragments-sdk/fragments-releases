# Fragments for Mac

The first signed download is being prepared. Installers and update metadata will be published here; application source remains private.

Fragments requires an Apple Silicon Mac running macOS 14 or later. Picture features require macOS 15.4 or later. Sign in to Fragments and connect your coding agent to work on a project.

Once the first release is available, download its DMG, open it and drag Fragments to Applications. Future releases can be checked from **Fragments → Check for Updates…**. The app checks daily and waits for active work to finish before restarting to install an update.

Update checks contact GitHub, which receives your IP address and app version. System profiling is disabled.

[Fragments website](https://usefragments.com)
