# Fragments releases

Download Fragments from [Releases](https://github.com/fragments-sdk/fragments-releases/releases/latest).
Installers and update metadata are published here; application source remains private.

**Mac:** Apple silicon, macOS 14 or later. Download the release's DMG, open it and drag Fragments to Applications.
Check for updates from **Fragments → Check for Updates…**.

**Windows:** Windows 10 or 11, x64. Run the installer, then open Fragments from the Start menu. Windows may warn
about an unsigned installer: choose More info, then Run anyway. Check for updates from **Help → Check for updates**.

Sign in to Fragments and connect your coding agent (Claude Code or Codex) to work on a project.

The app checks for updates after launch and daily, downloads updates in the background, and installs when you quit.
It never restarts by itself. **Restart to Update** waits for active work to finish.

Update checks and downloads contact GitHub, which receives your IP address and request information.
